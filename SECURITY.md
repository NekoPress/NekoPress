# Security Policy

## Supported Versions

Please report vulnerabilities against the latest public release first.

## Reporting a Vulnerability

Do not disclose sensitive vulnerabilities in a public issue.

Preferred path:

- GitHub private security advisory:
  - `https://github.com/NekoPress/NekoPress/security/advisories/new`

Fallback path (if private advisory is unavailable):

- Open a public issue with minimal detail and request a private follow-up channel:
  - `https://github.com/NekoPress/NekoPress/issues/new/choose`

Please include:

- affected version
- reproduction steps
- impact summary
- proof-of-concept (if available)

## Response Targets

- Initial acknowledgement: within 72 hours
- Triage decision: within 7 days
- Patch/release timeline: based on severity and exploitability
