# Security

Please do not report security problems in public issues.
Use **Report a vulnerability** on this repository's **Security** tab. Include the NekoPress version and the steps to reproduce.
Fixes are released as a new version. Only the latest release is supported.

---

보안 문제는 공개 이슈에 올리지 마세요.
이 저장소의 **Security** 탭에서 **Report a vulnerability**로 알려 주세요. NekoPress 버전과 재현 방법을 함께 적어 주세요.
고친 내용은 새 버전으로 배포합니다. 최신 릴리스만 지원합니다.
